# Architecture

## Components

| Component | Configuration |
|---|---|
| Static Web Apps | Standard SKU, React/TypeScript, direct Function endpoint |
| Functions | .NET 10 isolated, Flex Consumption FC1, Easy Auth v2 |
| Storage | Function host/deployment only、shared key disabled、Blob Private Endpoint、Public access Disabled |
| Foundry | New Foundry `AIServices` account + project + GPT-4.1 |
| Agent | Prompt Agent, generic MCP, `ask` allowlist |
| Work IQ | `https://workiq.svc.cloud.microsoft/mcp`, OAuth2 per user |
| Monitoring | One workspace-based Application Insights, 30-day retention |
| Secrets | Key Vault RBAC、purge protection、vault Private Endpoint、Public access Disabled、ARM child secret、non-secret expiry setting |

上記はIaCの目標構成です。既存環境は[閉域化の移行手順](private-network.md)に従って適用・検証してください。Web／APIの公開入口とFoundry／Work IQへの接続は維持します。

## Region rule

One `location` parameter is passed to Static Web Apps、Functions、Storage、Key Vault、Log Analytics、Application Insights、Foundry account/project/model. The preferred region is `eastus2`.

The following dependencies can't be pinned to an Azure resource region and are documented exceptions:

- Microsoft Entra directory objects
- Microsoft 365
- Work IQ Microsoft-managed SaaS endpoint
- Application Insights Smart Detection rule generated by Azure Monitor (`global`)
- Azure Private DNS zones and virtual network links (`global`)

Static Web Apps distributes static content globally even though its Azure resource has a regional location.

## Request flow

1. SPA signs in through MSAL authorization code + PKCE.
2. SPA obtains the Function API delegated scope.
3. Function Easy Auth validates issuer, audience, and application.
4. Function verifies tenant and the `ProfileChat.User` app role assigned through the dedicated allowlist group.
5. Function exchanges the user assertion for `https://ai.azure.com/.default` with OAuth OBO.
6. Function calls the project-scoped Foundry Responses API through the configured Prompt Agent.
7. Foundry selects the Work IQ `ask` tool and requests per-user OAuth consent when needed.
8. UI surfaces `oauth_consent_request` or `mcp_approval_request` and resumes with `previous_response_id`.
9. Function and Foundry send correlated telemetry to the same Application Insights resource.

## State

The UI stores visible messages and pending consent/approval continuation in `sessionStorage`. The API has no chat database. Foundry might retain response state required by OAuth continuation and tracing. Audit and retention follow Foundry、Application Insights、Work IQ、Purview policy.
